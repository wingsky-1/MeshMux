## 关键语义

**Subscriber ≠ Mesh Device ≠ VLESS Credential。** 可以有零代理用户的 Mesh-only 节点；一名代理用户可以关联多设备；设备撤销不得顺带注销其他用户。没有 Out 是合法配置，不得要求伪造一个 Out。首版流量统计仅在 sing-box 1.14.3 API 实机验证后才确定精度，实时精确配额不默认为已解决。
